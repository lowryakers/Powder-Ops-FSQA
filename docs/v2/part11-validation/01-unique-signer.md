# 01 — One person per signature (21 CFR 11.100(a), 11.300)

**Requirement:** every signature belongs to one named person: the person signed in. No typed names stand in for a
signature, and nobody signs off their own training.

**Who:** Daniela (Document Control) and Lowry (admin). **Time:** 10 minutes.

| # | Step | Expected result | Pass / Fail | Initials |
|---|---|---|---|---|
| 1.1 | Daniela: Document Control → Work Instructions → **New**. Number `TEST-P11-01`, title `TEST-P11 Validation document`, revision `V1`, status **Approved / Effective**, any text. Save. | A password box opens: "Approve TEST-P11-01 … your password is your signature". | | |
| 1.2 | Enter Daniela's password, Sign. Open the document. | Header reads **Approved by Daniela Servin** (her own name; there is no box to type an approver). | | |
| 1.3 | Lowry: Training → Records → **Add**. Employee **Lowry**, course any, tick "I confirm this person understands this training", Save, enter Lowry's password. | Refused: **"Nobody signs off their own competence — the trainer signs it."** | | |
| 1.4 | Lowry: same form, employee **Daniela Servin**, tick, Save, Lowry's password. | Saved. The record reads **Signed by Lowry**. There is no Trainer box to type in. | | |
| 1.5 | Open the training record from 1.4. | The trainer shown is **Lowry**, the person who signed. | | |

**Evidence kept:** the TEST-P11-01 document and the training record from 1.4.
